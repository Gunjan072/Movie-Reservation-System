How the AI Recommender Works

1. Content Feature Extraction: Each movie's genres, director, cast, language, and synopsis are transformed into a multi-dimensional TF-IDF (Term Frequency-Inverse Document Frequency) feature vector using Scikit-Learn.

2. Cosine Similarity Matrix: A pairwise Cosine Similarity matrix is computed across all {{ recommended_movies|length }} candidate movies to measure content closeness.

3. Hybrid Weighting (Collaborative Signals): Your confirmed bookings (3.0x), wishlist saves (2.0x), and profile genre preferences (1.5x) are used to weight similarity scores — forming a hybrid collaborative + content-based filter.
